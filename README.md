## 🚀 Featured Project

### DETEXION — Wearable Wireless Sensor Network

A wearable multi-node sensing system developed using:

**ESP32 + BNO085 IMU + ESP-NOW + FreeRTOS + Firebase**

The system collects motion information from multiple wearable IMU nodes and sends the data wirelessly to a central ESP32 gateway for processing and human-motion reconstruction.
